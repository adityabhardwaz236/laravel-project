# AI-Based Quiz & Certificate System - Implementation Guide

## Overview

This document outlines the newly implemented AI-Based Quiz & Certificate Approval System that integrates with Google's Gemini API to dynamically generate MCQ-based questions. Users can take quizzes and earn certificates upon passing.

## Features

### 1. **Dynamic Quiz Generation**
- Uses Google Gemini API to generate Multiple Choice Questions (MCQs)
- Supports 3 difficulty levels: Easy, Medium, Hard
- Flexible number of questions (3-20)
- All questions are saved to the database for future reference

### 2. **Quiz Functionality**
- Browse and take available quizzes
- Real-time quiz answering interface
- Automatic scoring with detailed feedback
- Explanation for each question's correct answer

### 3. **Certificate System**
- Automatic certificate generation for passing quizzes (60%+ score)
- Certificates include quiz details and score information
- Integration with existing blockchain certificate system
- PDF download capability

### 4. **User Experience**
- Responsive, user-friendly interface
- Track quiz completion and scores
- Review detailed answers after submission
- Retake quizzes to improve scores

## Setup Instructions

### 1. **Configure Gemini API**

#### Get Your API Key:
1. Visit [Google AI Studio](https://ai.google.dev)
2. Click "Get API Key"
3. Create a new API key for your project
4. Copy the API key

#### Update Environment Variables:
Edit your `.env` file and add:
```env
GEMINI_API_KEY=your_api_key_here
```

### 2. **Database Migrations**
The migrations have already been run, creating these tables:
- `quizzes` - Stores quiz metadata
- `questions` - Stores generated questions
- `quiz_results` - Stores user results and responses

### 3. **Dependencies**
All required packages are already in your `composer.json`:
- `guzzlehttp/guzzle` - For API requests
- `laravel/framework` - Core framework
- `barryvdh/laravel-dompdf` - For certificate PDFs

## Database Schema

### Quizzes Table
```
- id: Primary key
- title: Quiz title
- description: Optional description
- topic: Subject/topic of the quiz
- number_of_questions: Number of questions in quiz
- difficulty: easy|medium|hard
- created_at, updated_at: Timestamps
```

### Questions Table
```
- id: Primary key
- quiz_id: Foreign key to quizzes
- question_text: The question
- options: JSON array of 4 options
- correct_option: A, B, C, or D
- explanation: Why the answer is correct
- order: Question order in quiz
- created_at, updated_at: Timestamps
```

### Quiz Results Table
```
- id: Primary key
- quiz_id: Foreign key to quizzes
- user_id: Foreign key to users
- total_questions: Number of questions in quiz
- correct_answers: Number of correct answers by user
- score_percentage: Calculated percentage (0-100)
- passed: Boolean (true if >= 60%)
- responses: JSON object with detailed responses
- completed_at: When quiz was completed
- created_at, updated_at: Timestamps
```

## Usage Guide

### For Users

#### Creating a Quiz:
1. Click "Quizzes" in the navigation
2. Click "Create New Quiz"
3. Fill in the form:
   - **Quiz Title**: Name of your quiz
   - **Topic/Subject**: What the quiz is about (required by AI)
   - **Description**: Optional description
   - **Number of Questions**: 3-20
   - **Difficulty Level**: Easy, Medium, or Hard
4. Click "Generate Quiz"
5. The system will contact Gemini API and generate questions

#### Taking a Quiz:
1. Go to "Quizzes" section
2. Click "Start Quiz" on any quiz
3. Answer all questions by selecting an option
4. Click "Submit Quiz"
5. View your results immediately

#### After Passing:
1. View your score and detailed answers
2. Click "Generate Certificate" to create a certificate
3. Certificate is added to your profile
4. Download certificate as PDF

#### Retaking a Quiz:
- You can retake any quiz multiple times
- Only one result will be shown (the most recent attempt)
- Click "Retake Quiz" to attempt again

## API Integration Details

### Gemini API Request Flow
```
1. User creates quiz with topic and question count
2. System builds prompt with requirements:
   - Exact number of questions
   - Difficulty level
   - JSON format specification
3. POST request sent to Gemini API
4. Response validated and parsed
5. Questions stored in database
6. Quiz ready for users
```

### Question Format Generated by AI
```json
[
  {
    "question": "What is the capital of France?",
    "options": ["London", "Paris", "Berlin", "Madrid"],
    "correct_option": "B",
    "explanation": "Paris is the capital and most populous city of France."
  }
]
```

## Error Handling

### Common Issues and Solutions

#### 1. **"Failed to generate questions. Please try again."**
- Check if `GEMINI_API_KEY` is set correctly in `.env`
- Verify API key has quota remaining
- Check internet connection

#### 2. **"Could not parse Gemini response as JSON array"**
- API returned malformed response
- May indicate issue with prompt or API quota
- Check logs: `storage/logs/laravel.log`

#### 3. **Certificate Generation Fails**
- Ensure user has passed the quiz (score >= 60%)
- Check blockchain configuration if on-chain sync is enabled
- Verify required fields in certificate form

## Best Practices

### For Quiz Creators:
1. **Be specific with topic names**: More detailed topics generate better questions
2. **Start with fewer questions**: Test with 5-10 questions first
3. **Use clear difficulty levels**: Impacts question complexity and readability
4. **Review generated questions**: Always check first quiz to ensure quality

### For Quiz Takers:
1. **Read questions carefully**: Questions are dynamically generated, quality varies
2. **Review explanations**: Learn from incorrect answers
3. **Retake if needed**: Your best score is recorded
4. **Download certificates**: Save PDFs for records

## Advanced Configuration

### Customizing Gemini API Prompt
Edit `app/Services/GeminiService.php` - `buildQuestionPrompt()` method to:
- Change question format requirements
- Adjust difficulty descriptions
- Add specific constraints or topics

### Adjusting Passing Score
Edit `app/Http/Controllers/QuizController.php`:
```php
$passed = $scorePercentage >= 60; // Change 60 to any percentage
```

### Modifying Question Storage
The system stores complete responses in `quiz_results.responses` JSON field:
- User's answer
- Correct answer
- Whether it was correct
- Explanation
- Original question text
